This repository hands in a GTA VI launch-week meme posted on X for make.fun's "Post a GTA 6 meme on X" bounty. The post is the entry: its picture is a Vice City pay-receipt meme carrying make.fun's ghost and name, and POST.json names the post; main.ts copies POST.json to /output, which is all the program has to do.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
